About Me

Projects


Sorting Algorithm Identifier

Python tool

A benchmarking tool that runs and times QuickSort, MergeSort and BubbleSort across different input sizes and compares runtime and memory use. A suite of targeted test cases then works backwards: given the performance profile of an unknown algorithm, it classifies which sort produced it.

Built with Python. Automates timing and memory profiling and generates side-by-side comparison reports.


Absurdle Clone

Team project, Python

I directed a team project to build a Python clone of Absurdle, a word game that fights back. Its adversarial word-selection algorithm keeps narrowing toward whichever answer leaves the largest set of candidates alive each turn.

Built with Python and an object-oriented design: game logic, scoring and duplicate-guess handling are separate, reusable components. Procedural word-pool generation and optimized data structures reduce memory use.


Risk Dashboard

Web app, Accenture

An interactive web application that visualizes client risk profiles so stakeholders can act on data-driven intelligence. It helped reduce client risk oversights by 40%. It was fed by web scrapers and ingestion scripts I wrote to collect unstructured public and social media data.

Built with HTML, CSS and Python during my software engineering apprenticeship at Accenture.
