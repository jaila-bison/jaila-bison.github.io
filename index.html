Selected projects

Four projects. Select a title to open it.

  • An interactive visualizer for graph search. Draw walls, drop a start and a goal, then watch A*, Dijkstra and breadth-first search explore the grid side by side. I built it to study for my algorithms exam and kept adding features.

    Built with TypeScript, React and Canvas. Runs entirely in the browser.

    Code on GitHub Live demo

  • A marketplace where students buy, sell and trade textbooks, furniture and dorm gear within their own campus. Listings can be searched by course, and sign-in is limited to university email addresses.

    Built with Next.js, PostgreSQL and Docker. Tested with Jest and deployed through GitHub Actions.

    Code on GitHub Live demo

  • A command-line tool that searches very large log files quickly. It streams files instead of loading them into memory, searches in parallel across CPU cores, and highlights matches so the line you care about stands out.

    Built with Rust and standard-library threads. Benchmarked against grep on multi-gigabyte files.

    Code on GitHub Read the write-up

  • A classifier that reads course reviews and predicts whether the writer felt positive, neutral or negative. I trained three models on a labelled dataset, compared their errors, and built a small web page where anyone can try it.

    Built with Python, PyTorch, scikit-learn and Flask.
